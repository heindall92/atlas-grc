# Ilustraciones de Atlas GRC

Deja aquí las imágenes generadas con los prompts de `diseno/prompts-ilustraciones.md`.
La app las usa en cuanto existen; si falta alguna, muestra un fondo de color con un icono.

| Fichero | Dónde sale | Tamaño |
|---|---|---|
| `bienvenida.webp` | Bienvenida en 3 pasos (prompt 1) | 1400 × 1600 |
| `bloque-0-cabecera.webp` … `bloque-10-cabecera.webp` | Cabecera de cada bloque (prompts 2 a 12) | 1600 × 1000, mejor con fondo transparente |
| `bloque-0-portada.webp` … `bloque-10-portada.webp` | Portadas del carrusel de Hoy | 900 × 1200 |
